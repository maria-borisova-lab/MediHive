# Medical Care App
 
A modern web platform for booking doctor appointments, viewing laboratory results, and finding medical centers.
 
## Features
 
* **Interactive honeycomb layout** showcasing medical services.
* **Patient profile** and laboratory reports presented in an elegant blue-themed interface.
* **Location map** ("Where Am I Right Now") for quick access to nearby medical centers.
* **Online appointment booking system**.
 
## Technologies
 
* HTML5
* CSS3 (Custom Flexbox / Grid Layout)
* JavaScript (ES6+)
 
## Running the Project
 
Simply open `index.html` in any modern web browser.
