# 🏥 Medical Care App

Модерна уеб платформа за запазване на час при лекар, преглед на лабораторни резултати и намерение на медицински центрове.

## 🎨 Характеристики
*   **Интерактивна пчелна пита** с медицински услуги.
*   **Профил на пациента** и лабораторни изводи в стилна синя гама.
*   **Карта с локация** ("Къде съм в момента") за бърз достъп до близки центрове.
*   **Система за онлайн запазване на час**.

## 🛠️ Технологии
*   HTML5
*   CSS3 (Custom Flexbox / Grid layout)
*   JavaScript (ES6+)

## 🚀 Стартиране на проекта
Просто отворете `index.html` в какъвто и да е съвременен браузър.
